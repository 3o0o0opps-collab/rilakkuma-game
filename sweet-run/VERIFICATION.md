# 验证记录

验证日期：2026-11-25（Asia/Hong_Kong）

- 6 项 Node.js 测试通过：10,000 组生成路线都保留空车道；高速扫掠碰撞不会穿透；翻滚能够通过彩旗横梁；跳跃高度足够且稳定落地；换道耗时小于障碍行间隔；损坏或不可访问的 localStorage 能安全回退。
- 主脚本、场景脚本、音频脚本通过 Node.js 语法检查。
- 本地实机浏览器试玩确认开始、左右换道、跳跃、快速下落/翻滚、暂停、回到主页、失败结算、重新开始。
- 手机竖屏布局及桌面 1280×800 布局已目视检查。使用浏览器指针拖动验证一次左滑换道，遥测从中间车道变为左车道。
- 暂停时距离稳定在 6 米，跳跃高度与翻滚状态冻结；继续/主页按钮均可用。
- 一次实际游玩自动收集到 15 个布丁，在 101 米处碰撞野餐篮并显示结算和新纪录；刷新后读取到最高距离。
- 玩法说明可以打开和关闭；静音按钮的标签和状态切换正确。
- 优化后的一次运行采样约 60 FPS、359 次绘制、约 45 万三角形（含阴影阶段）；这只是当前测试机器的采样，不代表所有手机的性能保证。
- 最后一次浏览器错误日志为空。之前的一条阴影 API 弃用警告已通过切换为 PCFShadowMap 解决。
