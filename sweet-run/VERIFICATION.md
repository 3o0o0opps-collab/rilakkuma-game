# 2.0 验证记录

- 7 项规则测试通过。分别验证开局动作、地形与障碍覆盖、难度曲线、连续路线、高速碰撞、车道横移和历史纪录兼容性。

- 桌面和 390 × 844 竖屏检查了游戏画面。用指针拖动验证左滑换道，并确认暂停时距离停止更新。刷新保留旧版的最高分。
